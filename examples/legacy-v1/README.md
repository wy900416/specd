# Legacy v1 example

`demo-shop/` is the first specd reference graph. It predates the v2 sections
(`## Source`, `## Repo Profile`, `## Assumptions`, `## Agent Decisions`, and the
marker-delimited `## Validation` block).

It is frozen on purpose:

- do not copy it as a template;
- do not use it to learn the current format;
- use [`../poc-url-shortener/`](../poc-url-shortener/) instead.

It remains useful for seeing the mature-stage graph vocabulary (`implements`,
`exposes`, `consumes`, `part-of`) in one place.
